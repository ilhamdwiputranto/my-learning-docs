# My Learning Docs

Repository ini berisi dokumentasi praktik nyata, eksperimen kode, dan _proof of work_ untuk seluruh modul teknis yang terintegrasi langsung dengan web portofolio [ilhamdwiputranto.vercel.app](https://ilhamdwiputranto.vercel.app).

## 📁 Struktur Katalog

- `src/html/` — Praktik HTML (16 Modul)
- `src/css/` — Praktik CSS (34 Modul)
- `src/javascript/` — Praktik JavaScript (55 Modul)
- `src/database/` — Schema & Query Database
- `src/framework/` — Fitur & Komponen Framework
- `src/devtools/` — Konfigurasi DevOps & Tooling
- `docs/` — Catatan & Rangkuman Non-Teknis
